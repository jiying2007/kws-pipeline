# Branch history archive

This tag is an archival root, not a product or research release. Its commit has
one parent for the recorded main baseline and one direct parent for every
original branch head in [BRANCHES.json](BRANCHES.json). The complete original
commits and their trees remain reachable through those parent links.

The archival tree intentionally has no workflow, source, model or audio copy.
Use the manifest to recover an original branch at its exact commit. Do not merge
this archival commit into main; current integrated functionality and scientific
limits remain described by the repository main branch.

Original workflow files, old approvals and model candidates remain historical.
Restoring a reference does not authorize running those workflows or promoting
a model. No branch deletion is authorized by this archive itself.
