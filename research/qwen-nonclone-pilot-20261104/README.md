## Fixed experiment

One public preset (`Vivian`) from Qwen3-TTS-12Hz-0.6B-CustomVoice, revision
`85e237c12c027371202489a0ec509ded67b5e4b5`, generates exactly four requests:
`你好小窝`, `小窝小窝`, `你好小屋`, `今天晚上吃什么`. They are two positive
intents, one near-miss intent and one ordinary-negative intent. Requested text
is not proof of the spoken words. A single preset is not independent speakers.
Seeds are 20261104–20261107, without retries or replacement cells.

The fixed publisher model card explicitly identifies Apache-2.0 and the Vivian
preset: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice/blob/85e237c12c027371202489a0ec509ded67b5e4b5/README.md
The reused 13-file model snapshot lock binds 2,498,388,392 bytes, including
model/card/tokenizer identities. No voice-cloning rights are inferred from this.
Attribution: Qwen Team, *Qwen3-TTS Technical Report*, arXiv:2601.15621.

## Execution and limits

Only first creation of `research/qwen-nonclone-pilot-20261104-v1` in the public
`jiying2007/kws-pipeline` repository can run the dedicated workflow. It has no PR,
manual dispatch, schedule or workflow-run trigger. Branch/source/run identity,
run number 1, attempt 1 and frozen source hashes are checked before acquisition.
Do not delete/recreate a consumed branch or use a failed attempt as a fresh one.

An ordinary source PR branch cannot run inference. Its source is reviewable
before the experimental branch is created. The existing consumed experiment
branches, locks, receipts and numerical outcomes remain unchanged.

- One hosted Ubuntu 24.04 CPU job; 45-minute job limit and 40-minute inner limit.
- Setup at most 20 minutes; inference stage at most 25 minutes and capped by the
  remaining inner limit; each call at most 300 seconds. Failures stop the lane.
- Existing non-root Docker scope: 12 GiB RAM, no swap, 4 CPUs, 256 PIDs, read-only
  code/root, no capabilities, no-new-privileges, private cgroup/PID namespaces.
  Inference has network disabled; no credentials enter a worker.
- Retained downloader: model/runtime bytes checked against exact locks; setup
  input budget below 6 GiB and workspace budget 12 GiB; require 16 GiB disk
  reserve and 14 GiB available host memory. Image transfer is a monitored
  reservation, not a falsely claimed hard Docker-daemon transfer cutoff.
- Preserve actual setup/container/worker outcome receipts, including failures.
  Four planned cells remain the denominator if only a subset was attempted.
- Export at most 32 MiB of synthetic preset WAVs and bounded structured receipts;
  no runtime, packages, model weights or raw setup logs enter the artifact.

## Retained runtime boundary

transformers 4.57.3 and qwen-tts 0.1.1. It is not labelled current or generally
secure merely because an earlier run succeeded. Execution preserves the exact
runtime gate, safetensors-only weights, reviewed official sidecars, local-only
loading, `trust_remote_code=False`, disabled remote loaders and network-none
inference. This source does not authorize changing host security settings,
unreviewed dependencies, model sources or existing denied install operations.
Any platform review refusal stops the relevant action; no alternate executor is
a workaround for a denied operation.
