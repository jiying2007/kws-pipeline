# Causal MDTC dual-event research prototype

This is a 42,594-parameter from-scratch fbank80 adaptation of pinned Apache-2.0 WeKws code, not an official pretrained result. Three stacks of five dilated blocks plus a preblock produce RF377 frames (3.785 seconds including the 25ms feature window), 37,952 weight MAC/frame and 48,128 bytes logical FP32 stream cache. These counts exclude frontend and framework overhead and do not establish device performance.

Run standard-library tests with `PYTHONDONTWRITEBYTECODE=1 python test_static.py`. CI must run only this test command; do not install Torch or invoke a model, download data/weights, or start training.

Optional explicit synthetic numerical probe requires an already installed PyTorch 2.11.0+cpu. It uses no audio. `probe_synthetic.py` takes a fresh existing output directory argument and requires `MDTC_PROBE_AUTHORIZED=1`; it does not launch automatically. Run only with an external process supervisor enforcing 180 seconds, 2GiB process-tree RSS and 10MiB total output. The supplied process_supervisor.py is reusable standard-library code; use sys.executable as the Python command. Maximum 600 attempted forwards, one backward, zero optimizer steps. Identity CMVN is synthetic-only. This optional probe writes a randomly initialized, explicitly untrained state_dict/config; do not treat or publish that as a trained model. Future output limits must reserve measured serialization overhead rather than assuming parameter bytes equal file bytes.

The recorded first probe passed the fixed same-runtime synthetic atol=rtol=1e-5 comparisons. A separate single-file budget was exceeded: random state was 307,891 bytes versus 0.2MiB, although total output remained below 10MiB. It was not retried, compressed to disguise this exception, or included here. Thus not all execution gates passed. PROBE-SUMMARY.json contains anonymized actual outcomes. Optional reruns are new engineering tests, not replicas of the original run unless runtime and other identities are separately verified.

model.py consumes raw unspliced 80-bin log-fbank and applies CMVN internally once. Streaming forward is eval/no_grad and takes real frames only. Independent right-padded training returns logits only, discards cache, and requires complete-clip graphs. Unknown labels have zero direct supervised loss; another keyword being positive does not imply absence. Fixed BN statistics keep train and eval causal; affine parameters remain trainable. This normalization choice is an adaptation.

Raw PCM streaming is currently a contract, not an implemented frontend: 16kHz PCM16 mono, 400-sample complete windows, 160-sample hop, frame j available at sample 400+160j, no synthetic EOF tail, only real-session resets. config.json freezes the complete reference fbank options. Data admission and train-only CMVN provenance/verification remain unimplemented. No synthetic pass establishes training convergence, classification accuracy, FAR/FRR, C parity, quantization, or SSC305 qualification.

The upstream reference retains its Apache-2.0 headers and LICENSE. source-retention.json pins commit 6a45aeb994dd81c0969ff877a5a7c46d60ed0c86 and content hashes. Official MFCC80/dither1/3x4 differs from this fbank80/dither0/3x5 proposal. No pretrained weights are included or claimed.
