# 下一轮最小验证：输入、范围与停止条件

本文件是后续计划，不扩展已经完成的一次12条/1276帧受控回放。当前模型前向、训练、TTS、ASR新增预算仍为0，不追加VAD方案、阈值扫描、拼接片段或产品效果实验。

## 当前能确定什么

原C decoder在固定合成speech门、未校准.55条件下，从12条已暴露训练LP各产生一次目标词命中；1200ms镜像未抑制任何额外命中。这关闭了“仅标准beam句末能读出，原C是否也能形成命中”的有限问题。没有回答独立数据效果、真实VAD、词末延迟、短词误触发、连续负音频、真机时序或功耗。

## A. 现有资产即可进行的只读准备

这些工作不需要新声学输出，也不改变已停止实验：

1. 核对和整理本次技术证据、公开源哈希、固定条件、原输入身份与交付文件SHA256；保留原C命中和抑制镜像结果的区分。后续CI可验证源/定义/输出一致性及独立合成状态机fixtures，不应在CI重新调用已完成的训练入口或保存样本回放。
2. 只查已有manifest/归档元数据，列出是否存在与新A600完全绑定的可用checkpoint或.kwm、它们的来源与导出记录。本次证据明确reusable_weights_exported=false；没有发现对应artifact前按缺失处理，不能把旧公开模型充当当前候选。
3. 按现有数据清单梳理训练已暴露组、历史probe/校准/评估用途、说话人/声音/会话关联、重复PCM哈希及标注来源。仅有“probe”名称不证明未暴露或独立。已有机器标注样本不能直接升级成人工金标准；不打开音频、不偷看受保护评估内容来选方案。
4. 固定下一轮事件记录协议：每帧LP/logit语义、float格式、end_sample、speech_active的来源、真实VAD/外部AFE元数据、分块/断流/重置事件、decoder命中与最终输出。制定人工事件标签字段及匹配规则，但此阶段不收集新音频、不自动联系标注人员。

可完成的交付是证据目录、资产缺口表、候选输入合同和待批准的预算表；不能产出新的FAR或召回数字。

## B. 需要新数据或模型调用预算的最小声学验证

### 必需输入与当前缺口

| 必需项 | 最低要求 | 当前状态 |
|---|---|---|
| 唯一候选模型 | 与训练来源、导出器、量化方式、词表、前端几何、运行时提交绑定的artifact与SHA256 | 当前研究模型没有可复用导出；先做元数据盘点。若确实没有，只能另立预算产生可导出的候选，不能重启已关闭600/608入口 |
| 两词完整配置 | IDs、token映射、threshold、prefix/尾blank策略、retention及refractory全部冻结 | 公开配置可作为未校准基线；不能称为新候选校准结果 |
| 独立正例 | 未用于训练/调参的来源或说话人/会话组，明确数量与许可，人工确认完整词及起止 | 当前12条是已暴露训练正例，不合格作最终独立验证 |
| 关键混淆与负例 | 独立短词“小窝”、截断/跨边界片段、普通近音语句、连续背景/非目标语音；总时长和出处冻结 | 当前控制回放没有独立负例或负时长 |
| 事件真值 | recording ID、目标词ID、人工start/end、允许最早匹配时间、重复事件匹配与边界容差 | 缺失；必须在看候选输出前规定并确认，不能用LP或RMS预测代替人工词末 |
| 真正的控制轨迹 | 逐帧speech_active及其实际能量门/外部VAD来源，时间戳、断流、分块、重置记录 | 本次只有合成恒1门；RMS仅可作另行标注的派生代理 |
| 分离的数据用途 | 开发/校准集与一次性最终评估集隔离，按来源组去重，明确已暴露记录 | 需要重新核对，不能在最终评估集选阈值 |
| 新执行预算 | 精确数据manifest、候选数、最大模型前向/批次数或流式帧数、是否允许导出、重试/失败停止规则 | 未设定，当前新增预算0 |

### 最小执行顺序

1. 先完成A类只读准备；在候选artifact、数据manifest、标签/事件匹配协议和明确预算齐备前不启动新声学调用。预算以实际runner调用粒度写清楚，不能把“遍历一次”当作无限帧数或无限重试。
2. 只冻结一个候选及其配置。在独立开发材料上先校验数据格式、词表/前端身份、真实控制轨迹和事件评分器；若需校准阈值，预先规定搜索范围、目标、tie-break及失败条件，并仅使用校准集。不得在本次12条训练LP上选最佳阈值，也不得把校准结果当最终效果。
3. 冻结模型、配置和评分规则后，对未参与选择的最终评估manifest单次执行实际流式路径。保留原始decoder命中、抑制后输出和控制轨迹；不追加音频、不改切分或补静音来改善结果。若分块一致性被列为验证项目，要预先列明有限分块方案及调用预算。
4. 正例按人工事件真值报告正确匹配、漏事件、过早事件、重复/多余事件及真实词末到输出的时间分布；负例按实际可验证负时长报告多余输出数及预声明置信区间。两个指标使用各自真实分母，不能把12条正例或合成门测试转换成FA/h。
5. 预先确定产品目标、负例暴露时长和统计方法。若时长不足以支持目标置信界限，结论是证据不足，不称为“零误唤醒”。即使台架声学通过，也不自动获得真机资格。

当前需要明确的决策只有：采用哪一个可追溯候选、使用哪些获准数据/人工标签、独立评估与校准如何隔离、最大新增调用预算及业务验收目标。没有这些输入，下一轮停在合同与缺口准备阶段。

## C. 只有真实硬件链路能完成的验证

- 最终麦克风/外壳/扬声器回声路径以及实际BF/AEC/RES/NS/AGC后的语音与噪声表现；云端保存LP不能替代这些输入。
- 目标板CPU/内存峰值、实时裕量、端到端时间戳、功耗、温升和长时间稳定性；本地x86 C测试不是嵌入式设备性能测量。
- 真机连续采集的分块、XRUN、暂停恢复、路由切换、时钟/序号变化与状态清理，以及最终事件出口的重复抑制行为。
- 每次设备结果绑定固件/运行时/model/配置哈希、硬件与AFE版本、采集条件、许可和记录时间。缺硬件或真实记录时保持待验证，不用合成控制序列包装成真机证据。

## 所有后续步骤共同的停止规则

身份/哈希不匹配、数据用途混用、缺许可或人工标签、VAD来源不明、时间轴/分母不可核验、需要超出批准预算的模型/TTS/ASR调用时，立即停止相关执行并报告。未通过不自动触发额外训练、改阈值、换数据或扩大采集。当前已完成回放始终保持关闭。

## 归档与发布边界

技术代码、固定定义及公开源码元数据可先整理本地候选，并以无模型的静态/合成CI验证；远端发布仍按精确文件范围确认。native-output.jsonl中的float位模式可以还原研究LP，不能默认当作公开源清单元数据。研究输入、数值输出和数据相关结果应与公开代码候选分开审查；内部审查/代理记录、音频、权重、凭据及宿主二进制均不混入公开候选。
