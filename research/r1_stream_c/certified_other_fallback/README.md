# R1 OTHER 全竞争：保守上界与原 par4 精确回退（研究候选）

**状态：研究源码已提交，GCC/Clang 人工数组差分测试待仓库 CI 检查。尚未进行 owner 模型/PCM 实测。**
本目录是独立的、默认不启用的研究原型，不改变 R1 默认 SDK、ACTIVE113 权重、
ASR/TTS/训练、冻结阈值、历史失败记录或数据准入决定。

## 目标

ACTIVE113 在 130 条已知录音上保留事件与类别，但 113 个 OTHER 行是训练集
冻结子集；未选的 2,483 个 OTHER 行可能在新语音上获胜。
本原型保留原 2,601 行完整模型，执行：

1. 先按原 par4 双精度四路累加顺序计算 ACTIVE113 的 113 个真实 OTHER 行。
2. 首帧或重置后，对剩余 2,483 行逐行精确计算，保存完整残余最大值及隐层。
3. 后续帧建立保守浮点上界。仅当遗漏行的上界**严格低于**当前 113 行
   最大分数时才跳过全部残余；否则按原 par4 全量计算残余。
4. 精确回退后重新锚定证书。两条路径都要求输出原 2,596 个 OTHER 行的
   真实最大分数及其原始类别 ID；同分按更小的原始类别 ID 取胜。

不能仅以全局 argmax 相同证明安全，因为检测器可能也使用 OTHER 分数。
这里要求完整 OTHER 最大分数的同架构逐位保留。五个精确行仍由原 SDK
计算，未提供 2,601 维 logits/概率/CTC 接口。

## 保守证书

对于未保留 OTHER 行 j，定义原权重 q_ji、正 scale_j、偏置 b_j。
预计算 U_i = max_j scale_j * |q_ji|，并对非零系数向正无穷外扩一 ULP。
两帧的残余行**精确实数** affine 值变化不超过：

    sum_i U_i * |x_t[i] - x_(t-1)[i]|

额外加入保守舍入包络：
8192 * DBL_EPSILON * (1 + previous_magnitude + current_magnitude +
delta_upper + |previous_residual_upper|)，并再外扩一 ULP。
该包络预留了原双精度四路累加、缩放/偏置运算和证书累计的浮点误差裕量。
要求 IEEE binary32/binary64、RNE、渐进下溢、无 fast-math/FMA 收缩、
无超额精度且所有中间结果可计算；否则不发证书，执行原精确计算。
仅在上界严格小于已选 OTHER 最大值时才跳过，所以不会依赖
未经独立验证的经验 margin，也不允许用上一帧的陈旧最大值直接比较。
