一、结论

强预训练 FSMN 原权重现已封装成可构建、可运行、可安装和可独立调用的研究 C SDK。
包含 PCM16 流输入、固定前端、完整 2601 类 FSMN、完整关键词事件提议、错误处理、断流与重置。
本轮没有更换或训练权重，没有新增小模型、TTS 或 ASR。部署运行时不需要 Python/Torch、ASR、TTS、网络或下载。

工程落地的边界是：x86 Linux 研究 SDK 已实际运行；不是 SSC305 已上板，更不是独立真实语音效果已达标。
当前使用先前已单独验证的 Binary64 参考内核，并保留 float32 权重；并非优化后的 FP32/INT8 版本。
本轮通过的是 SDK 与既有 Binary64 参考的等价验证，不是 C 与原 Torch/MKL 的逐元素等价。
原 FP32/Torch 门仍为 FAIL；没有放宽、删除或改写原失败，也没有把 Binary64 的通过移作其通过。

七、复现与使用

解压 KWS_FSMN_R1_SDK_20261110.zip，在其同名目录执行：

sha256sum -c SHA256SUMS
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
cmake --build build --parallel 2
./build/fsmn_run --research weights/model.f32le weights/frontend.f32le --wav your_audio.wav

实时输入：
cat your_audio.pcm | ./build/fsmn_run --research weights/model.f32le weights/frontend.f32le --pcm -

WAV/PCM须已是16kHz、单声道、PCM16，SDK不隐式重采样。stdout是研究事件JSONL，stderr是运行汇总。
源码构建不需要Python/Torch；可选契约测试和所有者重放工具才需要Python。
编译后的x86主机程序只依赖其系统C/libm运行环境；不是ARM二进制。
README、MODEL_CARD.json、C头文件、examples/file_consumer.c、ARM工具链模板及manifest均在SDK包。

私有证据包包含原134条PCM和逐条预期哈希，可配合SDK的tools/replay_owned_capsule.py重放。
原Torch数值包与原锁定环境未重复装入SDK；其Library file_id及精确SHA列在私有证据包RECOVERY.json中。
不需要重训或重新生成音频来恢复本检查点。
