# R1 全类别 OTHER：INT16 预筛＋原 par4 精确回退

**研究候选，仅输出头原型，不默认启用。** 保留全部 2,596 个 OTHER 类别、完整原 INT8 权重、五个精确输出、骨干、前端、检测器和时钟，不改变已冻结 R1 或 ACTIVE113。

## 算法

1. 每帧以 140 维隐层最大绝对值选择对称 INT16 步长 Q=maxabs/32767；按 RNE 舍入到 ±32767。无法安全量化时完整原 par4 回退。
2. 全部 2,596 个 OTHER 行仍计算 INT16 × INT8 整数点积，按原比例和偏置重建近似得分。
3. 按实际隐层重构误差、原行 L1 权重和比例建立双侧数值界，额外加入 IEEE64 运算误差裕量及固定 1e-6 + 1e-8×|approx| 安全余量。
4. 取所有 OTHER 行近似得分区间的最大下界 L。仅当某行上界严格低于 L 时将其排除；其余行按原类别 ID 升序执行完全相同的双精度 par4，返回最终真实 OTHER 最大分数及原始类别 ID。异常浮点运算回退完整原头。

这里没有完整 2,601 维 logits 或概率接口，不能直接代替全部 CTC 后验。文件仍为原完整量化模型 1,960,140 bytes，无法继承 ACTIVE113 的 19.26% 文件节省；状态额外占有每行上界及权重绝对值和，CPU/PSS 实际收益尚未测量。
