# 2026-11-11：R1 CPU、mmap 与 OTHER64 固定试验

本次固定试验得到三个结论：六组实现的已保存帧／事件轨迹保持一致；CPU 分块实现没有显示稳定收益，mmap 的进程 PSS 没有下降；新的 `140→64→1` max-OTHER 头在开发集漏掉一个 K1 事件，按预注册规则淘汰。默认模型继续为 `R1-DEV-FSMN-20261107`。

数值与证据摘要见 [RESULTS.json](RESULTS.json)。该文件包含执行分母、固定参数、汇总指标、原始证据文件的 SHA-256，以及本目录执行源码的逐文件校验值。公开内容不包含 PCM、模型权重、检查点、隐层数组、预测数组、来源标识或逐样本轨迹。

## 2. 实现一致性与资源结果

`par4`、`block2`、`block4` 在 host 与 ARM QEMU 上组成六组。每组 134 条、12,534 帧、88 个事件，其中 K1 与 K2 各 44 个。804 份 F/E 文件与保存的原始基准逐字节一致，包括 argmax、事件、源时钟和交付时钟。独立审计核对了 843 个唯一完成声明、12 个二进制和 124 个生成源码文件；轨迹差异、非空调用 stderr、构建错误及源码／输入／模型漂移均为零。

CPU 使用不带轨迹捕获的 host 二进制，对同一个固定输入做 9 轮配对比较，按预定顺序轮换；QEMU 与轨迹捕获耗时不进入 CPU 结论。

| 内核 | CPU 秒／音频秒中位数 | 相对 par4 的配对节省中位数 | 配对胜出 |
|---|---:|---:|---:|
| par4 | 0.019229659 | 基准 | — |
| block2 | 0.019231485 | −0.004472% | 4/9 |
| block4 | 0.019452843 | +0.009672% | 5/9 |

配对节省取每轮比例的中位数，不等于两组中位数的比例。幅度接近零且胜出次数没有一致方向，本次未建立可用的 CPU 收益，保留 par4 默认实现。

内存以 par4 做 6 对 copy／只读 mmap 比较，轮换执行顺序；在实际流式处理后读取进程自身的内存统计。

| 指标 | copy 中位数 | mmap 中位数 | 配对 copy−mmap 中位数 |
|---|---:|---:|---:|
| PSS | 2,495 KiB | 2,495 KiB | 0 KiB |
| Private Dirty | 2,364 KiB | 448 KiB | 1,916 KiB |

Private Dirty 的下降没有伴随 PSS 下降，不能报告为本次进程实际物理内存占用减少。这里也没有峰值 RSS 或 SSC305 实板结论。39 次不捕获轨迹的资源运行验证了回执计数；其逐帧轨迹一致性并未单独测量。

本阶段仅证明保存的 F/E 轨迹一致，没有测试全量 logits 一致。此前原始 FP32 数值门仍为 `FAIL_UNCHANGED`。

## 3. OTHER 合并前置检查与 teacher 提取

前置检查对每条保存轨迹做一次原 token 回放、一次 OTHER 合并回放。保留 blank 与四个关键词 token，其余 token 映射到固定非关键词 sentinel；检测器源码、参数、事件格式和时钟均保持原样。合并改变了 742 个帧的 token ID，但两种模式均保留全部 88 个事件。这只验证保存 argmax 的检测器行为，不能说明学习到的 OTHER 估计准确，也不能证明概率校准或未见输入的一致性。

随后对固定 134 条输入各提取一次。GNU ld wrapper 通过既有 C 核心 trace 接口复制 stage 19 的 140D 隐层、原始五个精确 logits、其余 2,596 类的最大 logit，以及原始 winner／OTHER winner 和时钟。没有改变原计算，也没有保存全量 2,601 维 logits。独立审计验证全部 F/E 字节、帧时钟、最大值／平局重建、资格划分和哈希绑定。

## 4. 固定 OTHER64 候选：淘汰

候选冻结原 backbone 和五个精确输出，以一个 `140→64 ReLU→1` 网络拟合 max-OTHER，学习参数为 9,089 个，原精确输出参数为 705 个。运行类别明确为 **NumPy float64 隔离诊断**，不属于标准 Torch 重训练，也没有生成可替换默认模型的 C 导出包。

固定参数为：种子 `20261111`；SmoothL1，标准化空间 beta 为 1；AdamW 学习率 `1e-3`、weight decay `1e-4`、beta 为 `0.9/0.999`、epsilon 为 `1e-8`；2,000 次更新，每批 256 帧。每帧先均匀选择训练 clip，再均匀选择其中的帧，共采样 512,000 帧。X 与目标的均值／总体标准差仅来自 96 条已知训练记录，标准差下限 `1e-6`；`ctc_weight>0` 定义资格。固定一 CPU／一 BLAS 线程、600 秒绝对拟合预算，无早停、无扫描、无重试。

拟合前的自造小数组有限差分检查覆盖 11 个参数、ReLU 正负分支和 SmoothL1 两个区间，最大绝对梯度误差为 `7.1302e-11`。训练逐步保存损失日志，完整检查点和全部 130 条最终 OTHER 预测先持久化，再评分。评分复用原精确 logits 和未修改 C 检测器；平局规则固定为 `max_precise >= predicted_other` 时精确类获胜。

预注册规则要求开发集 34 条完整 E 事件流连同时钟全部逐字节保留；训练集不得新增事件或错误关键词事件。

| 汇总指标 | 已知训练集 | 已暴露开发集 |
|---|---:|---:|
| clip／帧 | 96／9,079 | 34／3,176 |
| 事件完全一致的 clip | 96/96 | 33/34 |
| 保留事件／基准事件 | 64/64 | 21/22 |
| 新增事件／丢失事件 | 0／0 | 0／1（K1） |
| 新增错误关键词事件 | 0 | 0 |
| 帧类别变化 | 13 | 15 |
| max-OTHER MAE | 0.925674 | 1.525633 |
| 绝对误差 p95 | 2.680328 | 4.731222 |
| 最大绝对误差 | 7.250384 | 11.378434 |

teacher 与候选的精确类／OTHER 平局数均为零。开发集 K1 弱标签正样本命中为 9/10，K2 为 10/10；两者各 24 条弱标签负样本均无误触。训练集 K1、K2 弱标签正样本分别为 27、28 条且均命中；负样本分别为 69、68 条且均无误触。这些计数不能报告为独立 FAR／FRR。

**33/34 不满足全量事件保留门，候选确定淘汰。** 已保存分数显示，OTHER 被高估，压制原本获胜的两个 K1 token；结合未修改检测器的四 token 匹配规则，可解释这一次漏检。这是保存证据的机制分析，没有重新推理。

训练集自身也显示误差结构：blank 占 87.06% 的帧，关键词帧占 6.78%；关键词帧 max-OTHER MAE 为 1.206，blank 为 0.873。比例是合并训练帧的描述统计，实际训练按 clip 均匀采样。后续研究方向只登记为**另行预注册的、仅依赖训练集的关键帧／决策 margin 目标**；本次没有增加运行预算、重训、开发集调参、阈值调整或校准，当前淘汰结论保持不变。

2026-09-30 的 [compact affine／sum-OTHER 实验](https://github.com/jiying2007/kws-data/tree/6f56614ba78273feb96024f4a7ec7ee4582af330/research/2026-09-30-compact-head-distillation) 仍为 `FAIL_FIDELITY`。本次 R1 非线性 max-OTHER 候选是不同试验，其失败不覆盖或撤销旧失败。max-OTHER 标量无法恢复其余 2,596 类的概率分布，不能宣称全量 2,601 类概率或 CTC 等价。

这些文件是保留源码的逐字节副本，保留原绝对路径、固定哈希和运行约束，**不是可移植的自动重跑入口**。其中 `read_hidden.py` 是准备好的可选读取助手，本次执行与审计使用各自独立解析器，没有调用该助手；其余文件用于已完成的执行、构建或审计。完整执行依赖原 owner 计划／清单／证据、固定模型与前端、对应源码树、生成的 C SDK、原检测器和交叉工具链。公开包供审查代码、参数、结果口径及证据绑定；逐样本复核依赖已保存的 owner 证据。

host 编译器为 GCC 14.2.0；ARM hard-float 编译器为 GCC 13.3.0，目标参数为 Cortex-A32、NEON-vfpv4。构建使用 `-O2`、`-fno-fast-math`、`-ffp-contract=off`、`-fexcess-precision=standard` 等固定选项。ARM 在 QEMU 上执行。拟合／评分使用 Python 3.12.14、NumPy 2.3.5；未使用 Torch 或 SciPy。
本次 ARM probe 的最高 glibc 符号依赖为 `GLIBC_2.35`，真实 SSC305 的 BSP、libc、动态加载器与固件 ABI 尚未验证；不能把 QEMU 通过解释成该二进制可以直接上板。

矩阵、提取和候选的独立审计均通过，但“审计通过”表示保存证据与拒绝结论可复核，不代表候选质量达标。候选审计最初由内联只读程序生成；后续保留的审计／失效分析工具及其私有逐帧报告仍留在 owner 证据中，本公开汇总只保留相应哈希与汇总量。此次没有新增独立自然负样本准入，没有完成实板资格验证，也没有模型晋升。
