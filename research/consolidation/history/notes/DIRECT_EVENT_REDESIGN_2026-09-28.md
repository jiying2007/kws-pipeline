# 从四音节 CTC 路径转向整词事件与显式拒绝的下一轮设计（reviewing）

## 为什么需要重设目标

当前 TinyStreamingRNN/H64 只输出空白与 `ni3/hao3/xiao3/wo1`，C 端通过四音节路径和固定阈值发事件。2026-09-28 已完成四条冻结配对：增加 18 条 ASR 合格 Qwen3、移除原 AISHELL3 128 条、增加 32 条受限负例音节并扩为七类、加入 22 条人耳/ASR 分证据的训练声线场景音频；四者在未训练声线正例、独立 Spark、真人近邻与代理场景之间都没有共同通过。[首音节顺序阻断](LEADING_SUFFIX_VETO_NEGATIVE_2026-09-28.md)在新扰动误杀真阳性。[场景增强](SCENE_TRAIN_AUGMENT_PAIR_2026-09-28.md)的词1经两套 ASR 均 0/6 精确接受，用户随后明确判定其中四条研究可用、两条 Uncle_Fu 错读；281 条混合收据训练仍使未训练声线词2降为 0/2。训练集 token 准确率接近 1.0 与 C 事件质量没有稳定对应关系。继续按同一个损失/小集扫权重、epoch、阈值不符合已设停止条件。

补充的[整词单 token CTC 原型](WHOLE_EVENT_CTC_PILOT_2026-09-28.md)在171条合格/受控来源上以 `<blk>,kw1,kw2,reject` 输出训练至600 epoch、CTC loss `0.011412`，却使已审未训练声线 0/4、独立 Spark 合格词1 0/2；训练声线词2的103帧后验甚至全为空白 top-1。900秒负例与真人近邻0次事件仅是过度拒绝。该负结果把下一阶段的重点进一步收敛到**可信词结束边界、迟发事件监督及正例覆盖**，不能再把“整词”简化成单个 CTC token。

随后一次[粗VAD尾帧监督](WHOLE_EVENT_TAIL_PAIR_2026-09-28.md)仍使已审未训练双词0/4，且固定900秒纯背景与近邻注入流在两个seed上分别触发292/324次。追加100条空转写背景的[单因素配对](WHOLE_EVENT_BACKGROUND_PAIR_2026-09-28.md)将事件降到67/69次，但两词仍0/4并出现词1被判词2，近场近邻事件也未清零。这说明**空白背景、目标事件时间和跨声线正例**是相互独立的训练需求；在当前少量同家族合成正例上继续调单 token损失/阈值不满足既定停止条件。下一版须先获得可复核的词结束时间和更广发音合格正例，再实现多任务事件头；不能把上述失败原型改名为已落地模型。

下列是**待实现设计**，不是已有模型效果或发布承诺。目标是让模型直接学习“完整词已结束”和“近邻应拒绝”两种流式决定，保留音节辅助监督供诊断；C 端使用同一帧时间轴输出事件和拒绝证据。它不能凭现有少量合成正例自动获得真人域泛化。

## 模型与训练契约

1. **输入与 ABI 隔离。** 保留现有 16 kHz 单声道、32 维 logmel、20 ms hop 和 H64 流式计算作为首个对照，新增模型格式/ABI 版本，不能让旧 ABI2 KWM/关键词包被新运行器误读。词1、词2与 reject 三路输出独立于原四音节 CTC head；实验默认保持开发用途。
2. **事件监督。** 对每条已审或严格 ASR 合格的完整目标词，先产生可复核的音节/词结束时间边界；只在最后一个目标音节完整结束的短窗口监督对应事件，其他帧为 none。起止边界和“连续词”低能量间隔先核，不能仅把整个短录音贴满事件标签。边界来源、教师模型及其 hash 写入清单；抽样人耳确认教师边界。没有可靠边界的音频只供 CTC 辅助或保留待审，不进入事件头正例。
3. **显式拒绝。** “窝小窝”“你好你好”“你好亚/呀”“你好小吴/屋/沃”等按实测音频/ASR 观察文本分层；仅当非目标词身份可信时监督 reject。来源文本与 ASR 不合时隔离或用单列的、明确限定负例的音节规则，不把生成输入文本伪装成真值。训练时正例和近邻按语音源、声线与场景分组，避免同一 clean WAV 的派生音频跨 train/holdout。
4. **损失与选择。** 事件头采用逐帧分类/序列事件目标，保留 CTC 辅助头但不让其代理分数决定模型晋级。正负采样质量由冻结全集计数确定，报告每词事件时延、正例召回、近邻事件和连续流事件；checkpoint 只按独立开发组的预声明共同门槛选择，封存软件检查组一次回读，不挑最低训练 loss 或反复扫描阈值。
5. **C 端闭环。** 新 ABI 模型先做浮点 Python 与 int8 C 逐帧一致性、流式分块不变性、边界/重启/长时资源检查，再实现有限状态事件整合与按词 refractory。所有调试/后验缓存绑定模型、词包、runner SHA；默认产品模型保持原状态，直到新 ABI 与软件门槛、实际 AFE/板端资格分别通过。

## 开工门槛与验收

- 先取得两个独立生成器的**发音可靠双词正例**，每个来源/词/声线分层报告 ASR 精确接受、人耳抽样、内部停顿、PCM 重复率和许可。当前 Qwen3 场景词1只有四条用户判定“尚可”，另两条错读；少量 Spark 只有部分 ASR 合格，均足以做接口 smoke，不足以据此估计泛化误差。事件正例训练须先扩大可信边界样本并冻结来源/说话人切分，不能把上述四条重复增强当成四位独立说话人。
- 保留已观察 Qwen3/HI-MIA/Spark 作为开发回归；新的合成源、声线或 session 先固定 split 和内容哈希，再封存一次软件检查。HI-MIA-CW 15 人只是已观察过的说话人隔离回读，不冒充新鲜资格；连续代理噪声流不等于家庭 FAR。
- 第一轮需同时达到已审双词未训练声线 4/4、近邻0，独立生成器两词不低于旧固定模型的相同 ASR 合格切片、真人近邻 7,006 条不高于旧模型 51 次，代理近场/中距近邻0、900 秒流0次；通过才增加多 seed 与长连续语音。任一门失败保留负结果并更新数据或结构假设，不改同一小集阈值求绿。
