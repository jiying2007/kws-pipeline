# Hey Mero V5 — frozen 43,876-param C11 streaming research path

**Scope:** exact causal FSMN-CTC model from public `kws-data` run [44495594627](https://github.com/jiying2007/kws-data/actions/runs/44495594627), artifact `14514228406`. No new training or data generation. This is not a released SSC305 model.

The `mero43_stream.h/.c` path implements 16 kHz mono PCM16, a center-free 512-point STFT with a 400-sample periodic Hann window and 160-sample hop, the source-trained 257×40 HTK filterbank, `log1p`, frozen train-only normalization, four 96-wide causal depthwise-memory blocks (4 previous projected frames), and four raw blank/HEY/MEH/ROH logits. It calls the **existing** `mero_ctc.h/.c` full-phrase greedy event decoder; there is no second English keyword or separate decoder.

The externally pinned packer `pack_mero43.py` accepts only the original model ZIP SHA256 `91b203f05041d92e7ffb1b748f94959ce19af6673b91dbc2144920815058d702` (actual 256-update research weights). The original ONNX SHA256 is `10bf30da57291f78f56db196db1137309f2c3b91dfe67bf0aa45ebb8cec05b1c`, original NPZ SHA256 is `02b7febf9f736fd70f4f9ae04042ffc6d609b15011d03d235b960f69b1d71696`. An unrecognized file shape, size, source hash, nonfinite tensor, nonpositive normalization scale, or invalid package is rejected.

Pack format: 8 bytes `MERO43V1`, little-endian uint32 version 1, uint32 float count 54236, then **exactly** 54,236 little-endian float32 values in original ordered `state_dict` tensors, Mel matrix, train mean and scale (216,960 total bytes). The generated model package is not committed, and its SHA256 must be pinned in device packaging. The runtime accepts only caller-supplied storage for the immutable model (~217 KB) and per-stream scratch (~15 KB); it does **not** allocate memory or touch files at inference time.

API: load once, initialize a distinct state per stream, then feed monotonically contiguous sample-numbered PCM blocks (≤16,000 samples). The callback gets raw four frame logits, the frame's evidence-availability sample count (not word-end timestamp), and any full-phrase CTC event. Dropouts must call explicit `en_v5_m43_discontinuity` to reset both frontend FSMN and decoder state, or `en_v5_m43_stream_reset` for a new stream.

## Reproduced original-PCM numerical evidence (2026-11-19)

These runs reuse the **same frozen** 43,876-param, 256-update Hey Mero model and the **same ten** independently machine-reviewed, original prospective DEV PCM files (2 synthetic positive and 8 ordinary). None is a new training, audio generation, user gold label or product approval.

- **PyTorch ↔ ONNX:** [kws-data run 44519849543](https://github.com/jiying2007/kws-data/actions/runs/44519849543), original 10-clip host evidence.
- **PyTorch ↔ GCC/Clang C11:** [PR #266](https://github.com/jiying2007/kws-data/pull/266) / [protected-main run 44541193521](https://github.com/jiying2007/kws-data/actions/runs/44541193521), all ten original PCM PASS; each frame token and complete-phrase event **counts** equal. Maximum observed absolute float32 logit delta **0.0001220703125** (predeclared bound 0.005, mean bound 0.0005). Proof artifact **14538062948**, SHA256 **050c0466a4abd588aa7778350db770e461b28e8f0ae641ffb3b6394d7442719b**.
- **x86 GCC C11 ↔ Cortex-A32 ARM hard-float ELF executed under QEMU:** [PR #267](https://github.com/jiying2007/kws-data/pull/267) / [protected-main run 44542782505](https://github.com/jiying2007/kws-data/actions/runs/44542782505), actual **10/10** original PCM PASS with identical model pack, exact **per-frame argmax token** and **per-frame whole-word event timestamp** equality, maximum observed absolute float32 logit delta **0.0**. Verified ELF32/ARM hard-float build and actual qemu-arm execution. Proof artifact **14538623972**, SHA256 **83045c21dbee6a7450a5f6ec268a52a5f1d2fe2add68afa76eccf13ff61279d3**.

These results establish a **host software numerical chain**, not board performance or acoustic model quality. The 2/2 synthetic accepted DEV positives and 0/8 ordinary triggers in earlier frozen comparisons are **diagnostic sample counts, not product FRR/FAR**; the 93K research challenger failed its 2 DEV positives and was not promoted. The old exposed DEV, CAL and LOCKED samples were not used for threshold tuning.

**Still NOT qualified:** physical SSC305/BSP PCM capture, on-device end-to-end callbacks, RAM/CPU/P95 latency and stability; independent realistic far-field 3–5 m human FRR, continuous natural FAR/h (target ≤0.1/h), calibration and unopened locked KWS test. Neither QEMU nor synthetic voices substitute for those gates. CTC max-gap/cooldown remain research controls. Do not label this model released or product-qualified; preserve fail-closed evidence identities, and do not reopen test data for retuning.
