# 独立 donor80 Kaldi/Hamming 前端研究组件

本目录只实现 C11 fbank80 与独立400维CMVN仿射运算。默认32维产品前端、发布模型、模型校验和根构建不变。尚未实现 C 拼帧、skip3、FSMN、解码器或模型导出，不能称为完整 donor 原生链或板端达标。

## 验收状态必须分开

- 原 v1 逐层契约仍然 FAIL：满幅正负交替PCM有20个FFT功率、10个mel值超过原逐bin误差界
- 经明确授权、先行独立审核后另立 v2“最终特征一致性”契约，正式验收 PASS；没有回写或放宽 v1
- 39个纯合成case、159帧：DC/预加重/窗/FFT输入逐bit一致；logfbank最大误差0.0001926422，小于原0.001门槛；测试链400维CMVN最大0.00003004075，小于原0.0002门槛
- 原静音/恒DC零值、系数、帧网格、有限值硬门保持；4组流式测试、7组CMVN测试通过
- 新增191项独立FFT测试通过，包括30个冻结向量、159个原黄金窗以及2个精确二进制缩放测试。最大误差/理论界比0.0562321，Parseval最大相对残差1.18131e-7

v2 在已知 v1 结果之后制定，采用明确的新验收范围。界限来自9层radix2浮点运算规模，DFT参考采用独立80位Decimal根表、模512索引与double忠实求和；不是按C已见误差倍数凑数。误差推导是注明假设的工程界，不是任意平台上的形式化证明。

## 固定数学与流式接口

16kHz单声道PCM16转float32，**不除32768**；400采样窗、160采样hop、相位0、snip_edges=true、不抖动、不补EOF静音。逐帧去DC，再以0.97预加重（首样本复制），乘非周期Hamming窗、补到512FFT，取未归一化功率、80个20Hz至8kHz连续mel三角滤波器、Nyquist权重0，再取ln(max(E,2^-23))。不追加能量项，不做跨mel均值、不用PCEN/log1p。

复用本仓库Apache2 FFT骨架，在独立目录改用一次舍入根表；原产品C数学没有修改或链接。官方float32窗/mel常量保留生成器与身份。目标是固定torchaudio源实现的供方Hamming推理路线，不证明未观察到的原始训练配置；WeKws默认Povey不同。

调用方拥有状态；单次输入0至16000采样，400采样时产生首帧，此后每160采样一帧，EOF丢弃不完整末帧。回调向量只在回调期间有效，要求单线程、不可重入。C源码无堆分配或显式文件I/O；这不等于操作系统零缺页或目标板实时性保证。

CMVN接口仍接收真实400维拼接向量，按(x−mean)×inverse_std计算。五段80维统计虽在当前donor逐bit相同，首版没有80维交换优化。允许精确原地运算，拒绝部分重叠、统计缓冲覆盖、非有限输入/输出和非正inverse_std，错误时不写输出。真实[-2,-1,0,+1,+2]顺序、仅左边缘复制、两帧右上下文和skip3相位仅由测试链核对；官方示例还有800采样的批处理门槛，不能与语义上720采样即可完整的上下文混为一谈。

## 重现与依赖

参见[英文构建、v1诊断及v2验收命令](README.md)。原生库只用C11/libm；NumPy是测试依赖，不是部署依赖。专用CI固定官方NumPy2.2.6 wheel URL/SHA，禁止隐式Torch/ONNX下载。555581字节的纯合成黄金包无损拆成12个≤48KiB片段，逐片及整包SHA/顺序/路径/长度全部校验后内存装配，仓库不保留重复整包；保留安全解包与源码生成器，不含私人音频或完整声学模型权重。重新从原始源生成oracle是单独的开发步骤；普通CI只读取固定向量。

状态结构4928字节、常量表载荷6816字节，不包含代码、栈、宿主运行环境，也不是实际板端RAM测量。软件验证可先完成；SSC305实际CPU、I/O、音频并发和长期运行应另行验收。此目录为隔离研究草稿，不进入默认产品运行链。

A32长期计数测试直接给现有调用方状态设置接近边界的合法历史，不新增测试专用API。样本数及帧数跨2^31/2^32、回调64位终点和UINT64溢出前原子拒绝均已通过。size_t只用于有界单块和缓冲索引，不用于持续时间轴。
