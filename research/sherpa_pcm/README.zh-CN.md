# 可选 sherpa PCM 研究适配层

本目录是独立的效果参考/备选入口，复用固定版本 sherpa-onnx1.13.8 官方 C API。不修改默认产品模型、src/include、根 CMake 构建或发布判定。当前 CPU 优先路线仍应重点研究紧凑原生模型；不能把本目录当作已通过 SSC305 验收的 SDK。

`pcm_kws.h` 提供创建、输入 PCM、检测回调、EOF、reset 和销毁。固定输入为16kHz 单声道 PCM16，内部320采样分块；解码参数与英文说明中的固定配方一致。模型只在创建时加载，reset 不重新加载模型。EOF 处理最后不足320采样的块但不补静音。回调文本仅在回调期间有效；只允许单线程、不可重入，回调不得抛异常、调用适配层或销毁实例。错误码覆盖参数、状态和可捕获异常；不能恢复上游 abort、非法指针或进程 OOM。ORT 仍可能分配内存或触发缺页，不具备默认产品实时数据面的无分配保证。

## 无模型测试

```
python3 research/sherpa_pcm/build.py --stub --output /tmp/kws-sherpa-stub
python3 research/sherpa_pcm/verify_dependencies.py
python3 research/sherpa_pcm/tests/test_parity_guards.py
```

使用已安装 GCC/G++ 和 Python 标准库，不下载依赖。stub 只检验生命周期，不执行语音推理；专用 CI 检查分块、reset、EOF、错误状态、重复创建销毁和输入证据校验。它不会进入默认产品构建。

## 真实运行时与本地回放

见 [英文构建和回放命令](README.md)。真实构建必须显式提供已审核的官方 C API 库，构建工具核对已固定的 x86 C API/ORT 哈希。源代码包只包含官方头文件及 Apache2 许可证，不包含模型、动态库、wheel 或可执行文件。ARM 版本需要单独审核的工具链与依赖锁，不能绕过 x86 哈希检查。

可选回放先验证固定42条参考报告哈希、非 stub 构建凭据、源码/动态库/运行时哈希和 WAV 文件身份，再加载原生库；PCM 解包后再次核对 PCM 哈希。拒绝越出数据根目录的绝对路径、上级路径、符号链接以及覆盖已有输出。三种输入分块方式的126条本地回放保持关键词、可用采样数与 EOF 标记完全一致。Python 只用于测试，不是原生库运行依赖。该组已观察合成片段不能证明真实远场 FAR/FRR。

## 性能与交付边界

旧研究 CLI 在 x86 上测得 CPU RTF0.018488、整进程 RSS60,204KiB，后者包含5,027,840B 预加载音频及运行时/模型/测试开销。已测 x86 安装组件合计37,938,029B，尚不含系统库和打包开销。这些数据既不是新适配层的性能实测，也不能推算 ARM 包体积、A32 延迟或精确模型工作内存。

用户确认 SSC305 为双核 Cortex-A32。可以先完成软件与合成/开源数据验证；板卡用于后续验收。BSP 的 libc/ABI/sysroot/编译器、算子支持和 NEON 运行环境尚需核实。最终测量需覆盖并行业务下 CPU 截止时间、真实 I/O/缺页、采集/DMA 和长期内存。当前环境没有 CMake/ctest，未运行根仓库完整测试，已明确保留该验证缺口。
