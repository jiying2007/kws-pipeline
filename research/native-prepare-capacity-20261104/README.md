# Same-job capacity-qualified native preparation

New independent identity: `research/native-prepare-capacity-20261104-v1`.
Only a first-created branch push, workflow run 1, attempt 1 can enter. Prior
prepare v1 and storage-probe runs remain consumed and are never rerun.

This host preserves the reviewed three-model, no-audio preparation workers and
source closure byte-for-byte. No model settings, inference, target maps, cleanup
of runner assets, or scientific scope are added. Full ASR remains unconditionally
blocked in the retained integration host. This campaign performs no recognition
or training admission.

The initial numeric workspace capacity is durably written in this same job
before comparing the unchanged 25 GiB free-space threshold. The existing
primary 16 GiB and Whisper 8 GiB setup guards remain unchanged. Thirteen fixed
before/after snapshots cover image acquisition, two setups and three preparations.
Later snapshots are observations, not new 25 GiB requirements. Snapshots are
sequential and not an atomic filesystem observation. Unavailable targets retain
only fixed status and numeric errno. Diagnostic failure cannot replace a primary
stage exception; any failure stops subsequent stages without retry.

The public allowlist contains only status.json (bounded statuses and hashes) and
capacity.json (run/head identity, fixed labels, numeric disk/device observations,
thresholds and explicit measurement limits). Raw paths, environment variables,
logs, audio, model/package bodies, transcripts, policy bodies and native payload
are not exported. Prepared native evidence remains runner-private. Existing
retained setup temporary-file cleanup and container teardown still operate;
there is no new capacity cleanup or removal of preinstalled/user data. Each
launch has a unique diagnostic parent, preserving prior diagnostics without
unlinking them.

A different runner's 91,610,882,048-byte observation does not authorize assuming
capacity here. Only this campaign's initial observation determines entry. The
same 1,800-second absolute inner budget, 120-second launch reserve and 40-minute
single-job bound apply. Tests use invented fixtures only; passing them is not
proof of a successful real preparation.
