## 解释限制与下一步前提

完整原句与单 token 删除句长度不同，Δ 只表示这两个完整目标序列之间的偏好；两者都未必是模型全局最偏好的转写。条件 CTC 对齐必须安排弱 reference 中的每个 token，归一化 q 不是“该音节实际发出”的概率。Viterbi blank gap 属于一条最优条件路径，不能作为人工音节时间；已保存的实际 argmax blank 统计另行保留。模型输入的 TTS 发音、弱文本正确性及来源差异仍需独立听审核查。

下一步若进入人工复核，应先固定完整 K1 与 K2 控制来源、重复 mention 的处理和不确定标签口径，再听原始音频，分别核查“好”的发音／省略、reference 错误和边界，不能用本开发集的数值挑容易样本或阈值。若安排后续 decoder replay，应事先固定解码设置与完整重放范围；本次 pairwise 对照本身不能替代该实验。任何后续学习或输入质量实验都应使用新冻结合同，并继续标明开发集已暴露，不主张独立泛化通过。
