## 3. 固定模型的起点对照定位了纯静音误输出

对先前 2000 步 C1 的同一组 8 条已知训练样本，0 ms 条件复用
已保存 logits；200/500 ms 条件只在原 PCM 前加入数字零。
本次共 16 次新前向、24 个条件观察，没有优化步骤或新增 ASR/TTS。

| 人工前导静音 | 全文 exact | Token edits / 32 | 纯新增静音中的 token 发射 |
| --- | ---: | ---: | ---: |
| 0 ms | 5/8 | 7/32 | 0 |
| 200 ms | 2/8 | 18/32 | 24 |
| 500 ms | 2/8 | 18/32 | 24 |

所有 16 个加静音条件均在纯数字零窗口的相同三个帧上产生相同的
非 blank token。24 个条件的原语音对齐特征 SHA 都与历史特征相同；
该观察支持继续修正模型的启动行为。模型权重在诊断前后完全不变。

## 4. 唯一固定修正的声明

修正使用同一零步初始化、同一组 8 条原训练音频和原 AdamW 设置，
固定 2000 步、batch 4。每条样本依次经历 0/200/500 ms，曝光次数为
334/333/333；总训练前向为 8000，最后完整读回为 24 次。

原全文 CTC 保持不变。新增监督仅使用人工补入的数字零：200 ms
对应 9 帧，500 ms 对应 24 帧，跨越真实语音起点的窗口排除。
辅助损失为这些窗口的平均 blank 负对数概率，系数固定为 1，
复用同一次完整前向。原音中的轻声或低能量区域没有被贴上静音标签。

预声明最低机制门槛要求全部 16 个带前缀条件的已知静音帧
均为 blank argmax，同时三个偏移条件各达到至少 5/8 exact、
token edits 不超过 7。严格 tiny-fit 另外要求 24/24 exact。
唯一候选无自动重试；固定系数是软监督，实际成败以终态结果为准。

训练启动包装会先验证 124 条声学校验的全部终态和保存回执，
再核对训练预封存并认领唯一任务。实现与研究边界见
[`research-c1-known-silence-correction.md`](research-c1-known-silence-correction.md)。

**当前状态：修正源码、声明和队列已经冻结，预封存已保存；
尚待声学校验全批次结束后实际运行。**
