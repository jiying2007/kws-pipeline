## 4. 唯一固定修正已完成，严格 tiny-fit 通过

修正使用同一零步初始化、同一组 8 条原训练音频和原 AdamW 设置，
固定 2000 步、batch 4。每条样本依次经历 0/200/500 ms，曝光次数为
334/333/333；总训练前向为 8000，最后完整读回为 24 次。

原全文 CTC 保持不变。新增监督仅使用人工补入的数字零：200 ms
对应 9 帧，500 ms 对应 24 帧，跨越真实语音起点的窗口排除。
辅助损失为这些窗口的平均 blank 负对数概率，系数固定为 1，
复用同一次完整前向。原音中的轻声或低能量区域没有被贴上静音标签。

预声明最低机制门槛要求全部 16 个带前缀条件的已知静音帧
均为 blank argmax，同时三个偏移条件各达到至少 5/8 exact、
token edits 不超过 7。严格 tiny-fit 另外要求 24/24 exact。
唯一候选无自动重试；固定系数是软监督，门槛在结果出现前冻结。

训练启动包装已验证 124 条声学校验的全部终态和保存回执，
核对训练预封存后认领唯一任务。实现与研究边界见
[`research-c1-known-silence-correction.md`](research-c1-known-silence-correction.md)。

真实队列在第一次尝试中成功退出，完成全部 2000 步、8000 次训练
前向和 24 次最终前向。未追加候选、步骤、ASR/TTS 或开发集训练消费。

| 人工前导静音 | 修正前全文 exact | 修正后全文 exact | 修正后 token edits / 32 | 已知纯零帧 / 其中非 blank |
| --- | ---: | ---: | ---: | ---: |
| 0 ms | 5/8 | **8/8** | **0/32** | 0 / 0 |
| 200 ms | 2/8 | **8/8** | **0/32** | 72 / **0** |
| 500 ms | 2/8 | **8/8** | **0/32** | 192 / **0** |

最低机制门槛与严格 tiny-fit 门槛均通过：24/24 条全文与原目标完全匹配，
264 个已知纯数字静音帧全部为 blank argmax，最低 blank probability
为 0.9999833107。24 个条件的原语音对齐特征 SHA 均保持一致，
最大特征差为零。三个条件的平均目标 CTC NLL 分别为
0.0017627909、0.0017232838、0.0021267071。

实际 queue 耗时 119.451 秒，worker 耗时 118.579 秒；单 worker
峰值 RSS 为 371,952 KiB。原冻结数值审计为 verified，审计新增
模型构造、前向和优化步骤均为零。终态包包含 162 个载荷文件，
大小 24,126,802 bytes；实际保存对象与完整哈希见执行索引。

本结论限于相同零步初始化、固定八条训练原音以及训练中曝光的
三个偏移条件。前缀曝光和辅助监督同时改变，不能将改善单独归因于
其中一个因素。这一成功尚未证明未见说话人、自然静音、真实轻声、
远场或自然 FAR 上的改善，也没有消除第 2 节独立短检查的空输出记录。
