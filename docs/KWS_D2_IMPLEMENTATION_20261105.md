# D2 数据计划落地与首批闭环

本文记录可重放的数据工程结果。候选计划量、原音返回量、技术完成量、
机器弱标签量和具体消费者的有效行数分别计数；没有将合成语音或 ASR
一致性当作独立人工真值。后续批次以各自的不可改写收据为准。

## 两仓库分工

`kws-data` 的 [PR #73](https://github.com/jiying2007/kws-data/pull/73)
已经合并：有界官方语料提取、32 人登记、D2 增量计划、独立的原音到
选择性 ASR 弱标签包，以及来源和角色重放检查。

本仓库新增 `research_d2_generate.py`、`research_d2_campaign.py` 和
`research_queue_supervisor.py`，将已有单模型队列串成真实执行链。
另有独立 D2 全文训练输入与消费探针；历史 D1 loader 和结果不被改写。

## 自动衔接与恢复

每个批次按以下顺序推进：有界 TTS 队列 → 原生 FLOAT WAV 导出 → 音频
ASR 输入 → Qwen 与 SenseVoice → 分歧及固定 20% 一致样本的 Whisper
复核 → 全证据弱包 → 独立重放 → 下一批。识别器不接收目标文本或其它
识别器的答案。原始 reference 文本只用于其已声明的克隆模式。

每个 stage 只有一个 driver 注册和运行锁。已认领调用不重试；完成
结果先认证再复用；失败、超时或未知任务停止推进。原生返回先于质量
筛选保存，技术失败原音仍可接受 ASR 审查，但不能因此变成训练标签。
导出核验 queue、claim、recipe、summary、inventory 及原音文件哈希。
JSON 格式变化不能重新注册同一 campaign。

当前两个完整声明分别最多 32 个八条批次和 96 个十六条批次。
生成队列总上限为 160 与 750 runner 分钟；包含对应 ASR 的 campaign
总上限为 480 与 1,710 runner 分钟，按所有实际任务纳秒累加。
每个模型任务最长 10 分钟，单项没有超过项目的 999 分钟上限。
这些是计算预算上限，不能当作实际已使用时间或预计完成时间。

所有重模型共用一个文件锁。driver 每五秒写心跳，等待已有 worker
完成后继续。`--max-chunks-this-call 1` 可以在同一冻结声明上完成一批
后暂停；去掉此运行参数即可沿同一声明继续，不能另建队列重跑旧样本。
详见 [`D2_CAMPAIGN_DRIVER.md`](D2_CAMPAIGN_DRIVER.md)。

真实 driver 使用已验证的 Python 3.12.16 ASR 环境及其 NumPy、SciPy、
soundfile；旧 core 环境缺少 soundfile，不能用于真实音频准备。
当前公开入口在任何新模型认领前检查并冻结 driver 环境。首批实际执行
源码另外保留在公开提交
`6f3aa456d31b455aa535a5319043db342dce4bf2`，其冻结工作树不被后续
环境预检加固覆盖。服务模板经过语法验证，但本次环境的 user systemd
离线，没有声称已安装永久守护服务。

## 训练消费与学习性分别验收

[`research-d2-consumption-probe.md`](research-d2-consumption-probe.md) 定义
独立 D2 输入、固定 2601 全文投影和有界消费探针。跨包唯一键使用
`source_id`，不能使用每包都会重复的 `clip-000`。全文从观察转写重投影；
legacy FSMN 数字 ID 不能直接冒充 D1 的 2601 词表。开发、OOV、失败和
不确定样本不得混入训练日程。原 D1 preparation 由其自身冻结源码
认证，原初始化和词表以精确哈希只读带入。

首批已经实际完成固定 C1 消费探针：25 步、100 次抽样，4 个训练源
各 25 次，两条普通负例均保留完整 8 token；开发前向为零。25/25 步
梯度有限且非零，16/16 个可训练张量实际改变，耗时 10.693694550 秒，
未超过预声明的 120 秒。独立审计通过，新增回读前向和优化步均为零。
终态仍为 4/4 空序列，不能解释为识别收益。匿名证据见
[`consumption25-summary.json`](../research/active-d2-20261105/consumption25-summary.json)。

本轮另已真实执行固定 8 个 D1 训练样本的小集拟合诊断：RNN64 与 C1
各 400 步，共 800 步、3,200 次曝光。梯度均有限非零，所有可训练张量
确实改变；最终整句匹配分别为 0/8 和 1/8，两者均未达到 tiny-fit
成功判据。总实际耗时 99.164039888 秒。没有根据结果追加步数、改目标
或重试学习率。详见
[`tiny-fit8-summary.json`](../research/active-d2-20261105/tiny-fit8-summary.json)
与 [`research-d1-tiny-fit-diagnostic.md`](research-d1-tiny-fit-diagnostic.md)。

数据入口可被消费、loss 下降和数据扩量均不能据此宣称 KWS 效果改善。
后续模型比较仍须使用相同目标、完整训练消费账本和冻结开发依据。

## 全方案尚需客观证据的部分

当前 D2 的上下文覆盖不足，句首／句中／句尾与连续呼叫使用独立追加
计划和独立观察验证，不能修改已冻结 D2 的身份或把声明当作已生成。
噪声、RIR 和连续流已有实现，仍需本轮实际素材与经验证母本的派生收据。

历史 AliMeeting 已有 8 会话、4.205 小时的真实连续回放记录，但其
已接受负时长仍为零、`expected=null`，不能当作自然 FAR 的已确认分母。
真人现场独立金标、实测房间与设备噪声、回放重录、SSC305 最终 AFE
以及真实回调延迟，需要相应原音、标注和设备测量输入；本轮的克隆
参考人、合成小时数和机器一致性均不能替代这些数据。
