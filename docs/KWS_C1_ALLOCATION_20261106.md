# 2026-11-06：固定 3:1 来源抽样实验

**该候选完成了执行和审计，但未通过预先冻结的描述性改进规则。** 该抽样策略候选的旧开发集全文错误减少，但丢失了 3 个原有 K1 命中，新开发集全文错误也增加。结论为 `mixed-improvements-and-regressions`；本轮不采用该候选作为改进方案，也不追加比例搜索。

## 实验范围与执行

对照为已经完成的 balanced64 混合模型。本次使用完全相同的初始 float state、96 条已准入训练记录、34 条开发记录、4 条零损失 unknown、weak 全文/target/mask/weight、模型、优化器、学习率、损失、种子和 2,000 步预算。每批 4 条改为旧来源 3 条、新来源 1 条，各来源内部按固定顺序循环，并沿用逐条访问的 0/200/500 ms 偏移周期。

因此比较的是完整抽样策略，包括 cohort 访问份额、批次组成及 row/offset 访问顺序；不是只隔离边际来源比例。对照旧/新来源分别访问 4,348/3,652 次，候选为 6,000/2,000 次；CTC weak-weight 累计值由 2,425.5/2,905.0 变为 3,346.5/1,591.0。权重累计值不是梯度贡献占比。

本次仅构造 1 个模型，实际完成 **2,000 次优化更新、8,000 次训练前向及 402 个最终条件前向**。队列端到端 209.06 秒，worker 207.34 秒；development 和 unknown 的训练访问均为 0。随后约 16.97 秒的保存结果审计返回 verified，比较和独立评分没有新增模型调用。没有重新执行原混合对照，没有新增 TTS/ASR。

冻结规则要求逐条保住每个开发集 control 正例命中、无新增已知负例关键词、old edits≤109、new edits≤31，并至少一项严格开发集改善。候选通过负例条件、旧全文上限和严格改善要求，**未通过“保住全部已有命中”和“新开发集 edits≤31”**。各条件分别判断，不允许用新增 K2 命中抵销 K1 丢失，也不允许用 old 改善抵销 new 退步。

## 保留的次要观察

old train 全文 edits 为 101/624 → 91/624，new train 为 7/192 → 29/192。训练集 K1/K2 的 row 命中数均保持，但 old train K1 实际有一个丢失命中和一个新增命中；数量持平不表示逐条保持，也不代表全文或开发集保持。200/500 ms 下开发集 K1/K2 的命中变化与 0 ms 相同；new development 全文 edits 为 30/68 → 34/68。全部偏移、训练/开发、已知负例及 unknown 均保留在完整配对记录，偏移条件不是独立样本。

独立评分器从保存的 greedy token 序列重新计算完整关键词存在性和 Levenshtein 错误分子，核验 402 对条件、相同输入与固定分母。它对两个 checkpoint 文件做字节哈希，0 次 tensor 反序列化、0 次数值 tensor 读取、0 次音频读取。执行计数和保存参数已审计；没有重放全部优化过程，也没有用这批结果选择 checkpoint、阈值、loss 或其他比例。

## 决策与后续

本轮排除了“这一个固定 3:1 候选满足既定非退步要求”的假设，不能推断所有重采样方法无效。模型、最终全精度 features/logits、原始执行计数、失败规则及全部配对结果均保留。后验诊断见 [KWS_C1_POSTERIOR_20261106.md](KWS_C1_POSTERIOR_20261106.md)；此前混合模型相对旧模型的事实见 [KWS_BALANCED64_20261106.md](KWS_BALANCED64_20261106.md)。

当前开发集已反复暴露，仍无 human gold、独立测试、真实人声泛化、自然 FAR 或 SSC305 实机验收。其余 192 个生成单元保持未启动；自然素材的目标存在性 unknown 和既有失败/unknown 调用不被改写为阴性或成功。后续应优先扩大可审查的自然语音候选覆盖、保留逐关键词 weak 证据，再冻结新的有界实验；本轮没有据结果临时改配额。
