# 活动区间与区间外 blank 的单变量对照（开发集）

## 问题与冻结边界

旧的 `grounded-ctc` 同时把 CTC 对齐限制在波形活动区间，并对区间外帧施加 blank 监督。它在冻结合成语音上改善了训练集可学习性，但现有结果无法区分两项约束的贡献。本实验只在 `training/startup_context_training.py` 的开发入口增加两种控制项；正式训练配置、模型结构、C 解码器、关键词阈值和产品门禁均不变。

固定语音池 `pool.json` SHA-256 为 `20346a75b33086d8085ebee7e72eacf4baad55c453a241e4f6babd710e222ce5`。训练仅读取 train；calibration 和 test 只用于开发反馈，qualification 不读取。固定 32 特征、H64 RNN、五 token 词表、seed、128 条训练记录、相同 batch/context 抽样、AdamW 0.001、600 epoch、目标长度归一化 CTC 和 0.55 关键词阈值。活动区间来自波形 2% 峰值且最小 64 PCM 幅值的包络，不能视作音素真值。

| 变体 | CTC 对齐区间 | 区间外 blank 权重 | 用途 |
| --- | --- | ---: | --- |
| `context-ctc` | 全片段 | 0 | 同上下文基线 |
| `span-ctc` | 活动区间 | 0 | 隔离活动区间约束 |
| `blank-ctc` | 全片段 | 0.3 | 隔离 blank 监督 |
| `grounded-ctc` | 活动区间 | 0.3 | 现有组合处理 |

四组都使用相同的 0/0.2/0.5/1 秒前置静音和 0.5 秒尾部静音。`plain-ctc` 不参加这组因子对照，因为它的上下文本身不同。先在 seed 1337 上用同一宿主与 Python 3.12/PyTorch 2.13.0 CPU 运行四组；若观察到改善，再以预先指定的 seed 2346 重复。检查初始参数、样本顺序、上下文顺序、源码实现 hash、冻结数据和 C runner 身份。

## 预设判定

用未改动的 C runner 分别看两词在 train/calibration/test 的每条音频、前置静音 0/0.2/1/2/5 秒和连续流中的命中、漏报与误触发，并看启动前缀反事实和纯静音。训练损失或 CTC NLL 只能解释机制，不能代替真实 C 事件。若某个单项控制能在两个 seed 下保持训练集可学习性，且 calibration/test 每词命中与误触发均不劣于组合处理，才考虑把它作为后续正式候选的研究方向；任何形式的开发集优化都不等于真人、最终 AFE 或板端放行。

本地对照在未提交工作树上运行时，训练收据中的 `source_worktree_clean=false` 必须保留；此类结果只作探索，不能冒充干净提交上的可复现 CI 证据。实验产物留在 `/tmp`，仓库仅记录脱敏计数、代码和验证命令。

## 本地同宿主结果

六次训练均完成 600 epoch。seed 1337 的四组具有相同的初始参数 hash `2678d580`、batch 顺序 hash `3c1c363e`、上下文顺序 hash `dd6278af`；训练实现 hash 均为 `ebe07af3`。模型均由原有导出器生成，使用同一冻结池和 SHA-256 为 `0599960f` 的 C runner。以下计数由实际 C 检测重算，格式为命中/正例、误触发；独立音频统一取 1 秒前置静音，连续流保持 2 秒间隔。词首前容差改为 0 ms 复算时，这些列的计数不变。

| seed | 变体 | train 独立 | train 连续 | calibration 独立 | test 独立 |
| ---: | --- | ---: | ---: | ---: | ---: |
| 1337 | `context-ctc` | 0/32, 0 | 0/32, 0 | 0/16, 0 | 0/16, 0 |
| 1337 | `blank-ctc` | 23/32, 0 | 23/32, 3 | 9/16, 4 | 11/16, 1 |
| 1337 | `span-ctc` | 32/32, 0 | 24/32, 0 | 14/16, 0 | 14/16, 0 |
| 1337 | `grounded-ctc` | 32/32, 0 | 32/32, 0 | 13/16, 0 | 13/16, 0 |
| 2346 | `span-ctc` | 32/32, 0 | 32/32, 0 | 13/16, 3 | 16/16, 5 |
| 2346 | `grounded-ctc` | 32/32, 0 | 32/32, 0 | 15/16, 3 | 16/16, 5 |

seed 1337 的 `blank-ctc` 连续流在 calibration/test 分别为 9/16、7 次误触发及 11/16、4 次误触发；`span-ctc` 和 `grounded-ctc` 在这两 split 的连续流与表中独立音频计数相同。seed 2346 的 `span-ctc` 与 `grounded-ctc` 连续流也与各自独立音频计数相同。纯静音、活动区词根及启动前缀反事实另保存在各组 `/tmp/kws-factorial-*-eval-20260927/summary.json`，不在表中折叠成产品通过声明。

**结论边界：**活动区间限制在此训练设定下是主要可学习性信号。只加 blank 监督不能达到训练集全命中，并在负例上误触发；只限制活动区间在 seed 1337 的连续流丢失 8 个训练唤醒，组合处理可补足，但 seed 2346 的活动区间单项已达到连续流全命中，因此 blank 的连续性收益具有 seed 依赖。组合处理没有稳定解决 calibration/test 误触发。seed 2346 的误触发主要落在不完整词、重复词和倒序近邻，而非完整的两条配置唤醒路径；任何单项处理都未达到预设的双 seed 非劣条件，正式配置保持原样。

下一次优化应针对近邻负例在真实 C 路径上的误触发建立单变量训练对照，同时保留活动区间约束、两 seed、固定阈值、独立片段和连续流检查。已有开发集被反复观察，新的正结果仍需独立语料与最终 AFE 验证。
