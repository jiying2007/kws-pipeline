# 启动上下文模型的近邻负例与语速扰动对照（开发集）

## 先定位误触发

在冻结语音池上，`grounded-ctc` 的 seed 2346 模型于 calibration/test 的 1 秒前置静音中分别产生 3/5 次误触发。逐条读取真实 C 检测，并对相同的 1 秒前置静音输入调用 C posterior dump 后，8 次误触发中有 7 次负例的 C 贪心路径已成为完整配置唤醒路径，另有一次 C 贪心路径不完整但解码仍接受。典型负例目标为 `[1,2,3]`、`[3,3,4]`、`[3,4,1,2]`，对应不完整、重复或倒序近邻。把已产生的 C 检测按置信度过滤到 0.9，calibration/test 仍分别留下 2/3 次误触发，并损失真唤醒；过滤只覆盖原阈值以上的检测，不能推断更低阈值行为。主要问题是未见声音上的声学混淆，单独提高阈值不足以修复。

冻结池 SHA-256 为 `20346a75b33086d8085ebee7e72eacf4baad55c453a241e4f6babd710e222ce5`。训练集有 8 个 TTS 声音、96 条非唤醒；calibration/test 各有 4 个独立声音、48 条非唤醒，12 类非唤醒目标序列在三个 split 中都出现。所有实验仅使用 train 更新权重，calibration/test 是已多次观察的合成开发反馈，qualification 未读取。模型仍为 32 特征、H64 RNN、五 token 词表，C runner SHA-256 为 `0599960febaccde62e09cede2a2adcba17a6d7665c792a2204f69ba1b21b3f39`，关键词阈值为 0.55。

## 负例路径损失

从同一 seed 2346、600 epoch `grounded-ctc` 权重出发，重置 AdamW 优化器并配对精修 36 epoch。对照继续原目标；两个处理仅在非唤醒转写上加入 0.1 权重的关键词路径 hinge，分别使用 C 可执行路径和稀疏顺序路径。两处理都有相同的初始权重、batch/context 顺序、输入和学习率。seed 1337 的可执行路径处理也与其对照配对运行。

| seed | 36 epoch 处理 | train 连续 | calibration 独立 | test 独立 |
| ---: | --- | ---: | ---: | ---: |
| 2346 | 无新增损失 | 32/32, 0 FA | 15/16, 4 FA | 15/16, 5 FA |
| 2346 | C 可执行负例路径 | 32/32, 0 FA | 15/16, 3 FA | 15/16, 5 FA |
| 2346 | 稀疏顺序负例路径 | 32/32, 0 FA | 15/16, 3 FA | 15/16, 5 FA |

seed 1337 的可执行路径损失在 36 个 epoch 均为零，处理与对照导出的 KWM 字节完全一致，SHA-256 同为 `3169efaf6d514e621cf4bd1b3da94958f39a822bfc5c44bbfa01680cfd14e0df`。seed 2346 的可执行路径损失仅第 1、4 epoch 非零，稀疏顺序损失仅 4 个 epoch 非零。训练负例的假唤醒路径过易，已训练模型上可持续施压的负例不足；两种损失都没有改善 test，不能提升为正式目标。

## PCM 语速与音高扰动

另一组从随机初态训练完整 600 epoch，仅把 train PCM 以固定 `0.85/1.0/1.15` 速率作线性重采样，转写不变。前置静音、活动区间 CTC、区间外 blank、batch 与上下文顺序均与无扰动对照一致；独立随机流选择速率。两 seed 各自的无扰动对照在新源码下重新训练，KWM SHA-256 分别与旧对照完全一致。seed 1337 的配对初态、batch、上下文 hash 前缀为 `2678d580/3c1c363e/dd6278af`；seed 2346 为 `78bbdd09/49bf4fd8/4ce6224a`。四次训练的实现 hash 前缀均为 `9a6847e4`。

| seed | 600 epoch 处理 | train 连续 | calibration 独立 | test 独立 |
| ---: | --- | ---: | ---: | ---: |
| 1337 | 无扰动 | 32/32, 0 FA | 13/16, 0 FA | 13/16, 0 FA |
| 1337 | 语速扰动 | 26/32, 2 FA | 11/16, 5 FA | 10/16, 2 FA |
| 2346 | 无扰动 | 32/32, 0 FA | 15/16, 3 FA | 16/16, 5 FA |
| 2346 | 语速扰动 | 32/32, 0 FA | 15/16, 1 FA | 14/16, 1 FA |

独立音频取 1 秒前置静音；四组连续流的 calibration/test 计数与表中各自独立音频一致。用词首前 0 ms、词尾后 500 ms 严格窗口重算，上表计数不变。seed 2346 的 test 漏唤醒增加集中在关键词 2：8/8 降至 6/8。seed 1337 则连训练集可学习性都未保留。`0.85/1.15` 是开发扰动，不是已验证的产品声学变化；不能因为其中一个 seed 的 FA 下降就推广该配方。

## 决策与边界

正式训练配置、关键词阈值、C 解码器和已发布模型均保持原样。两种负例路径损失缺少稳定训练梯度，语速扰动在第二个 seed 失败；本轮没有可提升的软件模型候选。进一步在相同合成 calibration/test 上搜索速率或权重会增加开发集选择偏差。下一步需要受控的真实双词正例、近邻负例和最终 AFE 后音频，重新冻结说话人分层与未见保留集；在该输入到位前，可做源码安全、评估契约与候选制品准备，但不能宣称模型已具备产品资格。

本地训练收据均记录 `source_worktree_clean=false`，实验只作为探索证据。模型、音频与逐条检测留在 `/tmp`，仓库仅保留脱敏计数、算法代码和 hash；/tmp 材料不是永久发布制品。
