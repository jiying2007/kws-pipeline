## K1 第二位“好”：全部 cohort

令 Δ = `log P(原完整 weak reference) − log P(仅删除该位置“好”的完整句子)`；q 为在完整 weak reference 条件下、逐原 target 位置归一化的 CTC 状态占用。表内 Δ、q 加权原始 P(好) 和“好−blank” logit 差均为 mention 中位数。箭头表示 baseline → augmentation。

| cohort | K1 row / mention | greedy 命中 | 删除 Δ | q 加权 P(好) | q 加权“好−blank”差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| old train | 17 / 21 | 11/17 → 13/17 | 0.9351 → 5.5525 | 0.619954 → 0.830880 | 0.4447 → 2.6730 |

开发集合计 K1 命中由 1/10 到 4/10。逐 mention 配对的删除 Δ 增益中位数为 old development **+7.0236**、new development **+8.5525**；其 8/8 和 4/4 个 mention 的 Δ、q 加权原始概率、相对 blank 差均改善。这些是同一批保存输入的配对描述值，不能把“两个组中位数相减”当作“配对差的中位数”。训练集也非逐项一致改善：old train 的 Δ 改善 14/21，new train 改善 8/10。

## 仍未命中的条目意味着什么

新开发集的 3 条 K1 漏报共 3 个 reference mention，其“好”的删除 Δ 全部为负，范围 **−2.8967 至 −0.5135**，中位数 **−2.4681**；q 加权 P(好) 为 **0.0341266 至 0.267252**，中位数 **0.0342316**；q 加权“好−blank”差也全部为负。这支持保存模型对该 token 与 blank／指定删除候选的竞争仍不足；不能据此证明物理音频中没有“好”。

旧开发集的 3 条 K1 漏报包含 4 个 mention，其中 3 个“好”的删除 Δ 为负。另一个 mention 的“好”确有较强支持（Δ **+2.8855**、q 加权 P **0.945474**），但同一 mention 的“你”却较弱（Δ **−4.0772**、q 加权 P **0.0138676**）；该 row 的另一个重复 mention 又存在“好”Δ **−0.6671**。这个例子不等于整条 K1 都有充分支持。

两组开发集共 6 条 K1 漏报，**原完整 weak 全文的 CTC log probability 均低于各自保存的 greedy 全文**。这不是通用 beam 的执行结果：含 K1、但其他字不同的候选仍可能存在；本轮没有声称 beam 一定能救回，或一定不能救回。

## 解释与后续边界

本次所有目标均来自原 observed weak full_text/target_ids/masks/weights，没有用期望朗读文本替代。logP 和上述 posterior 描述值未再乘 weak confidence；训练损失中的 weak 权重另行保留。条件对齐被要求安排每个 reference token，q 不是“这个音节确实被说出”的概率，Viterbi 窗口也不是人工音节时间。删除 Δ 比较不同长度的两个完整序列，不是全局最优转写或 decoder 正确性的证明。

结果支持继续检查固定来源分配下的学习行为，但不能预言后续 3:1 配额会改善，也不能证明本次改善由某一种来源质量或采样比例单独造成。训练集与已暴露开发集的用途不变；无 human gold、独立测试、真实人声泛化、自然 FAR 或 SSC305 硬件验收结论。若后续主张“解码可救”，须另行冻结参考无关的 decoder，在完整控制／负例上一次重放，不进行宽度或阈值 sweep。
